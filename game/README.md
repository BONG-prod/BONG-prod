# BONG RUNNER

An original browser platformer built with Canvas, HTML, CSS and JavaScript.

## Features

- Autopilot is enabled by default and times jumps around gaps, crates and spikes.
- Four handcrafted stages that loop into another run after completion.
- Collectible energy coins, score counter and stage progress.
- Manual jump control with Space, Arrow Up, W or a tap/click on the game canvas.
- Pause with P; restart with the Restart run button.

## Local preview

Open `index.html` in a modern browser, or serve this folder with any static HTTP server.

## GitHub Pages

The repository workflow in `.github/workflows/pages.yml` publishes this folder to GitHub Pages. On first setup, enable Pages in repository Settings → Pages → Build and deployment → Source → GitHub Actions, then run the Pages workflow from the Actions tab.

The runner character and artwork are original and do not use Nintendo or Super Mario assets.
